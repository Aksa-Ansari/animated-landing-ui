# animated-landing-ui
This project is a smooth GSAP-based image animation where three beautiful nature images slide into view along with animated text. The page uses HTML, CSS, and GSAP to create a simple animation effect.

## Features
- Smooth GSAP width animations  
- Text reveal animation synced with image transitions  
- Minimal and clean layout  
- Infinite looping animation

## Technologies Used
- HTML  
- CSS  
- GSAP
